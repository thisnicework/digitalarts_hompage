01전공소개

아직 세상에 없는 예술을
여기서 처음 만든다

2003년에 문을 연 영상학부 디지털아트전공은 과학기술을 바탕으로 '새로운 형태의 예술(New Form Art)'을 만듭니다. 3D와 애니메이션, 비주얼 이펙트, 인스톨레이션에서 인터랙션 프로그래밍과 인공지능까지, 도구와 코드를 예술의 재료로 배웁니다.

CODE 크리에이티브 프로그래밍

코드를 매체로 배운다

크리에이티브 컴퓨팅 디지털아트 프로그래밍 뉴미디어 프로그래밍
주요 도구 Python · C++ · Processing · GLSL Shader

알고리즘과 수학적 사고를 예술적 표현 도구로 전환합니다. 픽셀 조작, 실시간 인터랙션, 생성 예술(Generative Art) 시스템을 직접 코딩하여 구현합니다.

SOFTWARE Python · C++ · Processing · GLSL Shader · openFrameworks
PROJECTS 생성 예술 시스템 · 실시간 셰이더 프로그래밍 · 알고리즘 아트워크
CAREERS 테크니컬 아티스트(TA) · 크리에이티브 코더 · 인터랙티브 시스템 엔지니어
3D · VFX 컴퓨터 그래픽스

모델링에서 렌더링, VFX까지

3D 테크닉 I·II 캐릭터 애니메이션 비주얼 이펙트 디지털 머티리얼
주요 도구 Maya · Blender · Houdini · Substance · Nuke

상상 속 오브젝트와 유기적 캐릭터를 3D 공간에 조형하고, 절차적(Procedural) 효과와 실사 렌더링을 결합하여 압도적인 시각 경험을 완성합니다.

SOFTWARE Autodesk Maya · Blender · Houdini · Substance · Nuke
PROJECTS 시네마틱 3D 월드 · 절차적 VFX 시뮬레이션 · 실시간 인터랙티브 에셋
CAREERS 3D 제너럴리스트 · VFX 시뮬레이션 아티스트 · 비주얼 디렉터
TOUCH 피지컬 컴퓨팅 & 인터랙션

센서와 장치가 관객에 반응한다

피지컬 컴퓨팅 디지털 인스톨레이션 피지컬 시스템 디자인
주요 도구 Arduino · Teensy · 센서 네트워크 · 커스텀 PCB

스크린을 벗어나 마이크로컨트롤러, 모터, 센서, 전자회로를 다루며 관객의 물리적 움직임과 호흡에 유기적으로 감응하는 인터랙티브 조각 및 공간 장치를 제작합니다.

HARDWARE Arduino · Teensy · Raspberry Pi · 센서 네트워크 · 커스텀 PCB
PROJECTS 키네틱 아트(Kinetic Art) · 피지컬 인터랙션 조형 · 반응형 인스톨레이션
CAREERS 인터랙티브 인스톨레이션 아티스트 · 피지컬 엔지니어 · 공간 경험 기획자
SPACE 공간 & 무대 미디어 연출

공간과 무대를 미디어로 연출한다

미디어와 공간연출 모션 기반 미디어아트 미디어 퍼포먼스
주요 도구 TouchDesigner · MadMapper · Notch · Resolume

건축 파사드, 무대, 전시 공간 전체를 캔버스로 삼아 다채널 프로젝션 맵핑과 오디오 반응형 비주얼, 조명 제어를 통합하는 몰입형 환경을 연출합니다.

SOFTWARE TouchDesigner · MadMapper · Notch · Resolume Arena · DMX/MIDI
PROJECTS 대형 프로젝션 맵핑 · 오디오비주얼 라이브 퍼포먼스 · 몰입형 전시 환경
CAREERS 미디어 파사드 디렉터 · 오디오비주얼 퍼포머 · 무대 미디어 연출가
ENGINE 실시간 게임엔진 & XR

실시간 엔진과 가상현실 XR

게임엔진 테크놀로지 가상현실 콘텐츠 리얼타임 영상 제작 유니티 프로그래밍
주요 도구 Unreal Engine 5 · Unity 3D · Meta Quest

언리얼 엔진과 유니티를 활용한 실시간 렌더링, 버추얼 프로덕션, 가상/증강현실(VR/AR/XR) 공간을 설계하여 관객이 자유롭게 탐험하는 인터랙티브 세계를 구축합니다.

ENGINES Unreal Engine 5 · Unity 3D · Meta Quest · SteamVR · C# · Blueprints
PROJECTS 인터랙티브 XR 가상공간 · 실시간 인터랙티브 게임아트 · 버추얼 프로덕션
CAREERS XR 테크니컬 아티스트 · 게임엔진 디벨로퍼 · 메타버스 공간 디자이너
AI 크리에이티브 AI & 테크 창업

발상부터 데이터, 창업까지

AI와 크리에이티브 씽킹 데이터 분석 및 AI 활용 창업과 AI 비즈니스
주요 도구 ComfyUI · Stable Diffusion · PyTorch · LLM API

최신 생성형 AI 모델과 데이터셋을 창의적으로 제어하고 커스텀 파이프라인을 구축하여 새로운 예술적 문법을 탐구하고, 테크 스타트업 창업 모델로 확장합니다.

AI STACK ComfyUI · Stable Diffusion · PyTorch · LLM API · Runway · HuggingFace
PROJECTS 생성형 AI 인터랙티브 파이프라인 · 데이터 기반 예술 · 미디어 테크 창업
CAREERS AI 크리에이티브 디렉터 · 생성형 AI 파이프라인 엔지니어 · 미디어 스타트업 창업가
STUDIO 4대 캡스톤 디자인 실습

창작의 결실을 맺는 4대 캡스톤 디자인 실습

제작 파이프라인 아이디어 발상 → 산학 융합 프로젝트 → 캡스톤 실습 → 졸업전시회
디지털아트 창작실습 I·II 산학 프로젝트 스튜디오 포트폴리오 워크숍

4개 학기에 걸쳐 팀 및 개인 단위로 대규모 융복합 창작 프로젝트를 기획·제작·전시합니다. 현장 전문가 1:1 크리틱과 산학 협력을 통해 글로벌 비엔날레 출품과 고도화된 포트폴리오를 완성합니다.

STEP 01 창작실습 I 기초 프로토타입 검증
STEP 02 산학 프로젝트 산업체 실무 연계 멘토링
STEP 03 창작실습 II 본작품 제작 및 고도화
STEP 04 포트폴리오 & 전시 졸업전시 · 공모전 출품
OUTCOMES 서울예대 디지털아트 공식 졸업전시회 출품 · 비엔날레 및 국내외 미디어아트 공모전
PORTFOLIO 1:1 교수진 크리틱 기반 취업·진학 맞춤형 완성형 인터랙티브 포트폴리오
03진로와 역량 · Trajectories

당신이 만든 세계가
누군가의 현실이 된다

확장 미디어(Extended Media)와 인터랙티브 테크(Creative Tech), 두 역량을 축으로 모든 교과를 설계했습니다. 산업 현장과 현대 미디어아트를 아우르는 전문 창작 진로 영역입니다.

Creative Direction

전시·공연·미디어파사드·몰입형 공간의 총괄 연출과 내러티브 및 시스템을 설계합니다.

Computational Visuals

Interaction & Code

인터랙션 프로그래밍 · 피지컬 컴퓨팅 & XR

센서·하드웨어·공간 컴퓨팅과 인공지능을 결합하여 관객과 반응하는 인터페이스를 구현합니다.

Contemporary Media

빛, 소리, 공간, 데이터를 조형 언어로 승화시키는 실험적 인스톨레이션과 라이브 퍼포먼스를 탐구합니다.

Venture & Research
